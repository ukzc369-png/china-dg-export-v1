# 第一阶段技术 SEO 实施计划

## 目标

在不改变现有前端视觉和业务表述的前提下，让搜索引擎无需执行 JavaScript 也能读取核心页面、产品页和文章页的独立标题、摘要、正文主题、内链与结构化数据。

## 范围

1. 为首页、产品列表、服务、市场、洞察、关于和联系页面生成可抓取 HTML。
2. 为已发布文章生成独立的标题、摘要、H1、文章结构化数据和上下文内链。
3. 保留产品页预渲染，并补充面包屑结构化数据。
4. 确保预渲染内容位于 React 根节点内，前端启动后由现有页面正常替换，不产生重复可见内容。
5. 继续排除后台、重定向页和无独立内容价值的 URL。

## 验收标准

- 每个可索引路由具有唯一 title、description 和 canonical。
- 首页输出 Organization 与 WebSite JSON-LD。
- 文章页输出 Article 与 BreadcrumbList JSON-LD。
- 产品页输出 Product 与 BreadcrumbList JSON-LD。
- 无 JavaScript 时仍可读取页面 H1、摘要和至少两个有效站内链接。
- React 正常运行时页面外观与交互不变。
- 单元测试、TypeScript 构建、Vite 构建和预渲染全部通过。

## 不在本阶段处理

- 页面视觉重设计。
- 未经证实的库存、合作、资质或交付数据。
- 俄语及其他语言目录。
- 外链建设、广告投放和内容批量生产。
